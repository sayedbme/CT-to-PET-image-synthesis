# Region-aware CT-to-PET image synthesis using deep learning models for accurate lung cancer localization

Fig. 1. Overall workflow of the proposed CAD system for PET-CT image analysis. The pipeline integrates FOV correction using YOLOv11, synthetic 18F-FDG PET generation via a CPGAN, ROI cropping, tumor segmentation using SegResNet, and final PET-CT fusion for enhanced tumor visualization.
